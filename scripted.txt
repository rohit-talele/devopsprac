STEP 1: Create HTML Files
mkdir my-html-site
cd my-html-site

Then create the 3 HTML files:
echo "<h1>Welcome to Home Page</h1>" > index.html
echo "<h1>About Us</h1>" > about.html
echo "<h1>Contact Us</h1>" > contact.html
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
STEP 2: Upload Files to GitHub
Create a new repository on GitHub (e.g., html-deploy-demo) and add all html files to the repo
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
STEP 3: Install Required Jenkins Plugins
In Jenkins:

Go to Dashboard > Manage Jenkins > Plugins > Available/Installed

Make sure these plugins are installed:

✅ Git Plugin – Clones repositories

✅ Pipeline Plugin – Enables pipeline jobs

✅ SSH Plugin – Optional: used for remote SSH execution

✅ HTML Publisher Plugin – For publishing HTML reports (optional)
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
STEP 4: Set Up Jenkins Pipeline Job
Go to Jenkins Dashboard

Click "New Item"

Enter name like HTML-CI-CD

Select "Pipeline" → Click OK

Scroll to the Pipeline section

Set Definition: Pipeline script

Paste this script:
node {
    stage('Clone Repository') {
        git branch: 'main',
            url: 'https://github.com/YOUR-USERNAME/html-deploy-demo.git'
    }

    stage('Deploy to XAMPP') {
        def targetDir = 'C:\\xampp\\htdocs\\html-website'
        
        echo "Creating deployment directory at ${targetDir}"
        bat "if not exist ${targetDir} mkdir ${targetDir}"
        
        echo "Copying HTML files to XAMPP..."
        bat "xcopy /Y /Q *.html ${targetDir}\\"
    }

    stage('Deployment Complete') {
        echo "Website deployed! Open: http://localhost/html-website"
    }
}

####################Replace the repo URL with your actual GitHub repo.####################
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
STEP 5: Prepare XAMPP Environment
Make sure XAMPP is installed at C:\xampp

Start Apache from XAMPP Control Panel

Ensure folder: C:\xampp\htdocs\html-website is empty or ready for deployment
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
STEP 6: Run the Jenkins Job
Click Build Now on the HTML-CI-CD pipeline job

Wait for the stages:

✅ Clone repository

✅ Create folder

✅ Copy files

✅ Deployment complete

Open browser: http://localhost/html-website/index.html
